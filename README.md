# TCE-GO TI 2027 — Plano de Estudos

App de estudos para o concurso **Técnico de Controle Externo — Tecnologia da Informação** do TCE-GO (Tribunal de Contas do Estado de Goiás).

- **Prova:** 17 de janeiro de 2027
- **Banca:** FCC (Fundação Carlos Chagas)
- **Cargo:** Técnico de Controle Externo — Especialidade: TI
- **Salário:** R$ 11.862,19 + benefícios

## O que tem no app

- ✅ Plano semana a semana (Set/2026 → Jan/2027) com 111+ tarefas
- ✅ Tópicos do edital completo com checkboxes
- ✅ Simulado com IA gerando questões no estilo FCC
- ✅ Cronograma mês a mês
- ✅ Podcasts por tema no Spotify
- ✅ Anotações e registro de sessões de estudo
- ✅ Funciona como PWA no iPad (adicione à tela inicial)

## Como usar no iPad

1. Abra **Safari** e acesse `https://SEU-USUARIO.github.io/tce-go-estudos/`
2. Toque em **Compartilhar** (ícone de caixa com seta)
3. Toque em **Adicionar à Tela de Início**
4. Confirme o nome e toque em **Adicionar**

O app abrirá em tela cheia como um aplicativo nativo.

## Tecnologia

HTML + CSS + JavaScript puro. Sem dependências externas obrigatórias. Dados salvos em localStorage do navegador.

O simulado de questões usa a API da Anthropic (Claude Sonnet) — funciona automaticamente quando conectado à internet.
