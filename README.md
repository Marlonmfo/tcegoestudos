# TCE-GO TI 2027 — Plano de Estudos

App de estudos para o concurso **Técnico de Controle Externo — Tecnologia da Informação** do TCE-GO.

- **Prova:** 17 de janeiro de 2027
- **Banca:** FCC (Fundação Carlos Chagas)
- **Salário:** R$ 11.862,19 + benefícios
- **Inscrições:** 05/10 a 06/11/2026 — concursosfcc.com.br

## O que tem no app

- Plano semana a semana — Set/2026 a Jan/2027 com 100+ tarefas
- Gran Cursos integrado — links diretos para cada aula
- PDFs obrigatórios — Lei Orgânica, Regimento, CF/88, LGPD e mais
- Tópicos do edital completo com checkboxes
- Simulado IA gerando questões no estilo FCC
- Cronograma mês a mês
- Podcasts por tema + Playlist do carro no Spotify
- Anotações e registro de sessões de estudo
- PWA — funciona como app nativo no iPad

## Como usar no iPad

1. Abra o **Safari** e acesse: `https://marlonmfo.github.io/tcegoestudos/`
2. Toque em **Compartilhar** → **Adicionar à Tela de Início**
3. Nome: **TCE-GO TI** → **Adicionar**
